# Acceptance criteria

- Stable recognizable face across frontal, profile, full-body, and outfit scenes.
- Natural beard/hair variations do not change underlying identity.
- Photorealistic default; stylized optional; no silent drift.
- Expression and gesture cues fit the scene; stillness is allowed.
- Real product catalog includes verified URL, timestamp, price, currency and alternatives.
- Autonomous style selection is explainable, reversible and approval-gated for spending/publication.
- No canonical image or identity weights uploaded without public release confirmation.
- Existing Hermes/Ollama/Qwen/OpenCode installations remain unmodified by visual setup.
- Local generation and optional LoRA training pass real hardware tests before being marked operational.
