# Real-product fashion catalog

Use `python scripts/fashion_catalog.py add --file product.json`, `list`, `outfits`, and `verify`.

Each record must name a **real product** and a source URL, price with currency, observation timestamp, retailer, and optional size/stock information. Product data are snapshots, not guarantees of current availability. Never fabricate inventory or prices.

A catalog item is not a purchase. FayZawn may select virtual outfits autonomously; financial transactions and public posts remain approval-gated.

No invented seed products are provided. Add real listings only after research and source verification. Keep unverified editorial inspiration in a separate reference category.
