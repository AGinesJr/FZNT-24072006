# Research protocol

1. Discover actual clothing and hairstyle references using current sources.
2. Prefer official product pages; capture retailer, price, currency, size availability, date, and URL.
3. Distinguish verified product listings from editorial inspiration.
4. Compare similar products and price tiers. Explain tradeoffs and mark stale information.
5. Record source and timestamp; never infer real-time stock from old cached data.
6. Keep network research opt-in for private-mode operation. Never send canonical face images to a fashion retailer.
